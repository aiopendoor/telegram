# 🌌 Antigravity: 자율형 멀티 에이전트 생태계 (Agent-Centric Master Blueprint)

## 📌 1. Mission Statement (진화하는 에이전트 사회)
이 시스템은 단순한 데이터 파이프라인이 아닙니다. 각 부서는 특정 역할과 자아(Persona)를 부여받은 **독립된 에이전트(Agent)** 들의 거주지입니다. 
정보를 수집하는 '수집가', 지식을 정리하고 저장하는 '사서', 전략을 세우는 '참모', 행동에 나서는 '집행관', 결과를 반성하는 '감사관'이 각자의 임무를 수행하며, 서로 소통하고(M2M) 진화하는 **'하나의 인공지능 회사(Company)'**를 구축합니다.

---

## 🏢 2. 에이전트 기반 폴더 구조 (The Agent Society)
기능 중심의 파편화된 구조를 탈피하여, 완벽한 **에이전트 역할 중심(Role-Based Architecture)**으로 폴더 체계를 통합 관리합니다.

### 👑 `00_Core` (신경 중추 및 글로벌 규칙)
전체 에이전트 사회의 법률(Core Rules)을 정하고, 공통의 맥락을 제공하는 메인 시스템입니다.
- **역할**: 에이전트 간 통신 규약 정의, 글로벌 환경 변수(.env) 및 시스템 설정 파일 관리.
- **주요 파일**: `.env`, `00_System_Config.md` (동적 분류 기준), `blueprint.md`.

### 👁️ `10_Collector_Agents` (수집가 / 센싱 요원)
외부 세상의 변화를 끊임없이 감지하여 날것의 정보를 물어오는 정보원들입니다.
- **역할**: 텔레그램 실시간 감지, DART 공시 추적, 경제 지표 크롤링.
- **산출물**: 판단이 배제된 날것의 텍스트(Raw Data)를 20번 Database 요원에게 전달.

### 📚 `20_Database_Agents` (사서 / 기억 및 정제 요원)
수집가(10)가 가져온 혼돈을 정리하여 **지식 저장소(Memory)** 에 기록하는 지식 엔지니어들입니다.
- **역할**: LLM 기반 데이터 정제, 비정형(Obsidian/NotebookLM) 및 정형(Supabase/DB) 데이터로의 분류 및 저장 관리.
- **담당 저장소**:
  - **Memory (Unstructured)**: Obsidian 및 NotebookLM 기반의 연결된 지식망.
  - **Warehouse (Structured)**: Supabase 기반의 시계열 데이터 및 활동 로그.

### 🧠 `30_Strategy_Agents` (참모 / 분석 및 전략 요원)
기억(20) 속에 축적된 데이터를 분석하여 가설을 세우고 최적의 실행 전략을 수립하는 두뇌 그룹입니다.
- **역할**: 퀀트 분석, 부동산 트렌드 예측, 비즈니스 기사/쇼츠 기획서 작성.
- **특징**: 현실 세계에 직접 개입하지 않고 오직 고도의 '기획서(Strategy Signal)'만을 생산합니다.

### 🦾 `40_Product_Agents` (집행관 / 실제 행동 요원)
참모(30)들의 기획서를 바탕으로 물리적/재무적 현실에 영향을 미치는 행동파들입니다.
- **역할**: 실제 주문 체결(Trading), 영상 업로드(YouTube), 블로그 포스팅, 제안서 발송.
- **안전장치**: 예산 및 리스크 규칙(00_Core 참조)에 위배되는 행동은 즉시 거부하며 로그를 남깁니다.

### ⚖️ `50_Control_Agents` (감사관 / 평가 및 진화 요원)
집행관(40)이 행한 행동의 결과(수수익률, 조회수 등)를 복기하여 시스템을 업그레이드하는 개선 전문가들입니다.
- **역할**: 성과 평가, 오류 분석, 참모(30)들의 프롬프트 템플릿 자율 수정 제안.
- **목표**: 실패를 학습의 기회로 삼아 전체 시스템의 **'정확도 및 성공 확률'**을 지속적으로 상승시킴.

### 🛡️ `90_System_Agents` (관리인 / 인프라 및 보안 요원)
비즈니스 로직과는 독립적으로, 전체 시스템의 물리적 건강 상태와 비용을 감시합니다.
- **역할**: LLM API 토큰 비용 상한선 통제, 모듈 생존 신고(Heartbeat) 체크, 긴급 정지(Kill Switch) 관리.
